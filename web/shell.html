OpenTTD for phone

Please note: this app is intended for people who own a copy of Transport Tycoon Deluxe. If you don’t own the original game, please buy it before using this app.

Touch controls

  • Tap = click. Drag = scroll the map, or drag-build when a tool is selected.
  • Two fingers: drag to scroll (even with a tool selected), pinch to zoom.
  • Long-press = right-click (shows tooltips, closes dropdowns).
  • Side buttons: zoom in/out, “next tap is a right-click”, close top window (Delete key) / cancel tool (Esc), keyboard, this menu.
  • Rotation lock on? No need to unlock it: hold the phone sideways and the game turns itself. If it is upside down, use Flip upside down above.
  • If the interface is too small or big: OpenTTD menu → Game Options → Graphics → Interface size.

Saves

Games are saved inside this browser on this device. Export them now and then as a backup.

Using your own original Transport Tycoon Deluxe graphics & sounds

This app ships with the free OpenGFX graphics and OpenSFX sounds. If you own TTD on a computer, you can use its original files instead:

  • Find these files in your TTD install folder: TRG1R.GRF, TRGCR.GRF, TRGHR.GRF, TRGIR.GRF, TRGTR.GRF (Windows version) or TRG1.GRF, TRGC.GRF, TRGH.GRF, TRGI.GRF, TRGT.GRF (DOS version), plus SAMPLE.CAT for sounds.
  • Put them on your phone (e.g. iCloud Drive / Files), tap Import files… and select them all.
  • Reload, then in OpenTTD choose Game Options → Graphics → Base graphics set → Original (and the same for base sounds).

Your original TTD .SV1 save games can be imported the same way and loaded from Load Game.

Install

On iPhone: Safari → Share → Add to Home Screen. It then opens full-screen and keeps working offline.
